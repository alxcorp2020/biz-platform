> "입찰 발견 → 참여 → 제출 → 낙찰"까지 전 과정 / Free · Basic 플랜 기능 전체 포함
>
> 이 문서는 2026-08-08 로컬 서버 실제 화면 검증을 거쳐, 원본 시나리오를
> 현재 UI/동작에 맞게 정정한 판본입니다. 실제 테스트 시에는 예제 공고를
> 진짜 나라장터 공고로 대체해서 진행하세요.

## 📌 원본 대비 주요 정정 이력
1. **§1 회원가입** — "1단계 → [다음 단계]"의 2단계 마법사는 **폐지됨**. 지금은
   이메일·휴대폰·비밀번호·약관동의를 한 화면에서 받는 **단일 폼 + [회원가입] 버튼**.
2. **§3 대시보드** — 카드 구성이 "숫자 카드"에서 **행동유도 카드**로 재구성됨
   (참여검토 대기 / 마감임박 / 서류확인필요 / 담당자미지정 / AI 분석).
3. **§5 · §11 SMS 토글** — Free에서 SMS 토글이 **비활성화되거나 "유료 플랜에서
   이용 가능합니다" 툴팁이 뜨지 않음.** 토글은 플랜과 무관하게 항상 켤 수 있고,
   Free는 **발송 시점에만** 차단된다(실제 SMS 미발송). Basic 결제로 토글이
   "새로 활성화"되는 시각적 변화는 없다 — 차이는 실제 발송 여부에서만 난다.
4. **판정 등급 명칭** — 실제 4등급은 **참여 권장 / 조건부 참여 가능 / 확인 필요 /
   참여 곤란** (일부 요약 화면에서는 참여 권장이 "즉시 참여 가능"으로도 표기됨).
5. **§4 복제** — [복제] 클릭 시 **이름 입력 모달**을 거쳐 생성된다.

[최종 확인] AI 분석 커버리지 % 표시 → "이 정보로 분석을 시작합니다" → 대시보드로 이동

[확인 사항]

## 4. 맞춤공고 설정
URL: `/#/me/saved-searches`

화면 상단: AI 분석 커버리지 % / 매칭 신뢰도 / 검증 필요 항목 + 카테고리별 커버리지 바
(업종/면허/인증/재무/수행실적/인력). 탭 7개: **맞춤공고 · 담당자 관리 · 기업정보 ·
재무정보 · 수행실적 · 인력정보 · 면허·인증**.

[원본 확인]
"내 기본 조건" 카드가 온보딩 정보로 자동 생성되어 있는지 확인
(충청남도 · 시설관리/유지보수 · 소기업, 배지 **"온보딩 시 자동 생성됨"**).
→ 이 카드의 버튼은 **[결과 보기] · [수정] · [복제]뿐 — 토글/삭제 버튼 없음**(항상 활성).

[맞춤공고 복제]
"내 기본 조건"에서 [복제] 클릭 → **이름 입력 모달**에서 이름 확인/수정 후 생성
→ 생성 즉시 **비활성(토글 꺼짐)** 상태, origin 배지 없음(독립 조건).

[복제본 수정]
업종 "ICT/SW"로 변경 / 발주기관 키워드 "정보시스템" / 예산 1,000만~1억(듀얼 슬라이더) /
포함 키워드 "유지보수","관리"(태그) / 제외 키워드 "건설","토목"(태그) → 저장

[활성화 테스트 1 — 실패]
복제본 업종을 원본과 같은 "시설관리/유지보수"로 되돌린 뒤 활성화 토글 →
**"이미 활성화된 다른 맞춤공고와 업종이 겹칩니다"** 에러 모달(HTTP 409, 겹친 조건명 표시).

[활성화 테스트 2 — 성공]
업종을 "ICT/SW"로 다시 변경 후 활성화 → 정상 활성화(원본+복제본 공존).

[알림 설정] 카드에서:
- ☑ 추천공고 다이제스트 이메일 받기
- ☑ 제출마감 리마인더 받기 → D-7/D-3/D-1 선택
- 수신 담당자: (담당자 관리 탭에서 등록한 담당자 선택 / 미지정 시 계정 이메일로 발송)

## 8. 파이프라인 진행 (검토 → 준비 → 제출 → 낙찰)

제출완료 … + 하단 **"종결됨"** 접이식 그룹(낙찰/탈락/제외 등). 칸반에서 카드 드래그로 상태 변경.
표 뷰: 공고명/발주기관/상태/담당자/마감일/AI 판정등급/서류미비/최근수정일 + 상태 필터·정렬.

[8-1. 상세 진입 → 상태·담당자·메모]
- 상태 드롭다운: 검토전 → 참여검토 → … → 제출완료
- 담당자: 이름/이메일/전화 직접 입력, 또는 **[담당자 목록에서 불러오기]** · **[회원 목록에서 선택]**
  (담당자 관리에 미리 등록해두면 자동 채움) → 상태 변경 시 담당자에게 알림 발송
- 낙찰 금액(원): 낙찰 시 입력 → 성장분석 ROI 반영
- 메모 입력 → [저장]

[8-2. 제출서류 체크리스트]
구조화 추출이 완료된 공고면 필요 서류가 자동 매칭되어 [보유/미보유]로 표시.
아직 분석 전이면 "서류 분석 진행 중 — 완료되면 자동으로 채워집니다" 안내(정상).

[8-3. 캘린더] [📅 캘린더에 추가 (.ics)]로 다운로드 / `/#/calendar`에서 제출마감·개찰일시 확인(월/주/일 뷰).

[8-4. 제출완료] 상태 "제출완료"로 변경 → 담당자에게 상태변경 알림(이메일/웹푸시) 발송 확인.

[8-5. 개찰일 경과] 개찰일 지나면 "결과 확인 필요" 알림 → [결과 확정] → 낙찰/탈락/유찰 선택.

[8-6-A. 낙찰] 상태 낙찰 + 낙찰 금액 `58,000,000` 입력 → 성장분석 ROI 반영.
[8-6-B. 탈락] 상태 탈락.

[확인 사항]
- 파이프라인 한도(Free 3건)에서 **낙찰/탈락/제외 건은 카운트 제외**되는지
  (제출완료·보류는 카운트에 포함)
- 마감일 경과 후 진행이 없으면 익일 09:00 배치로 자동 종료(미참여) 전환되는지

## 11. 유료 플랜 결제 (Free → Basic)
URL: `/#/billing/plans`

[결제] Basic "가입하기" → 토스 결제창 → 테스트카드 입력 → 결제 완료

[결제 후 확인]
- `/#/me/subscription`에서 플랜이 "Basic"으로 표시
- AI 분석 한도 0 → 5건/월
- 파이프라인 한도 3건 → 무제한
- 결제 내역에 "신용카드"로 정확히 표시
- **⚠️ 정정: SMS 토글은 원래부터 켤 수 있었으므로 "새로 활성화되는" 시각적 변화는 없음.**
  플랜 차이는 실제 SMS 발송 여부에서만 나타난다(QuotaGuard 미도입 시 실제 발송은 별개).

[환불 — 미사용] 결제 직후 AI분석/파이프라인 신규생성 없이 "환불 요청"
→ "전액 환불 가능" 안내 후 처리, Free로 즉시 강등.
(과거 버그였던 "상위 플랜 환불 시 하위 유효 구독 소실"은 수정됨 — 유효한 하위 결제가 있으면 그쪽으로 복귀)

[환불 — 사용] AI분석 1건이라도 사용 후 "환불 요청"
→ "이미 서비스를 이용하신 내역이 있어 환불이 불가합니다" 안내 →
   "해지 신청"으로 전환(현재 결제 기간 만료일까지 이용 후 자동 Free 전환).

## 12. 성장분석
URL: `/#/growth`

- **AI 분석 커버리지·파이프라인 성과 추이**: 리포트 2건 이상 쌓이면 그래프(주간 월/매월 1일 자동 생성)
- **AI 참여판정 등급 분포**(도넛): 참여 권장 / 조건부 참여 가능 / 확인 필요 / 참여 곤란
  — "현재 열려있는 공고 전체를 지금 기준으로 다시 채점한 실시간 스냅샷"
- **ROI (낙찰금액 대비 비용)**: 총 낙찰금액/총 결제금액 (낙찰 금액 미입력 시 "계산 불가")
- **벤치마킹**: 전체 가입 회사 익명 집계 평균과 비교(AI 커버리지, 파이프라인 전환율).
  표본 5건 미만이면 "데이터 부족" 정직 표시, 개별 회사 데이터는 노출 안 함.
